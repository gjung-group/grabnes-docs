**`CalcSelect`** (public)

- `moireBLShift.Calc`: Sweep over rigid layer shifts (Moire.BLShiftDefinedValues or Moire.BLShiftRange): the on-site terms and the Kubo / Diag calculations are repeated for every shift.
- `Kubo.Calc`: Run the recursion calculation (CalcKubo): DOS or local DOS, then the time evolution unless Calculate.OnlyDOS.
- `Diag.Calc`: Run the diagonalisation calculations (CalcDiag): bands, DOS, spectral function, selected by the Calculate.\* keys.
- `Output.ReadDataFiles`: Take the hoppings from the file generate.s (one 're im' pair per line, units of g0) instead of computing them; the Peierls phases of a magnetic field are added after reading.
- `Tunn.Calc`: Write the interlayer sums T\_AA, T\_AB = -sum\_j t\_ij exp(i k.d\_ij) from each Species-1 atom of layer 1 to layer 2, at k = Tunn.BigKVecX/Y/Z (CalcTunn; files \<prefix>.TunnAAR, TunnAAI, TunnABR, TunnABI).
- `MagField.FrankMagneticField`: Alternative Peierls gauge of HamHopMagneticField (ham.F90); read here but not used in this routine.

**`CalcKubo`** (private)

- `Kubo.RecursionNumber`: Number of Lanczos steps (length of the continued fraction); sets the energy resolution. No reorthogonalisation: the useful length is bounded by the number of distinct levels the start vector sees.
- `Kubo.NumberofTimeSteps`: Number of time steps of the Kubo time evolution (KuboTEvol, only without Calculate.OnlyDOS).
- `Kubo.TimeStep`: Time step of the Kubo time evolution, in units of hbar/g0 (g0 = TB.Hopping).
